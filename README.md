Customer Churn Prediction Using Python and Machine Learning

Project Overview
This project uses machine learning to analyze customer data and predict whether a customer is likely to leave a telecommunications company.

Dataset
The project uses the IBM Telco Customer Churn dataset, containing 7,043 customer records.

Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

Project Workflow
1. Data loading and inspection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature encoding
5. Train-test splitting
6. Model training
7. Model evaluation
8. Classification threshold experimentation

Machine Learning Models
- Random Forest
- Logistic Regression

Key Results
- Random Forest achieved 78.8% accuracy.
- Logistic Regression with a 0.5 threshold achieved a churn F1-score of 61.3%.
- Logistic Regression with a 0.3 threshold achieved a churn recall of 92.5%.
